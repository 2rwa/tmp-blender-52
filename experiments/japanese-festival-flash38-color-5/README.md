# Workbench Color Test — five additional Japanese art models

Independent follow-up to the first five-subject Gemini 3.8 Flash Low trial.
Subjects: wagasa umbrella, chochin lantern, sensu fan, tsuzumi drum, kagura suzu bells.

### Specific test
Every assigned material must have both:
- `mat.diffuse_color = (r,g,b,a)` for Blender Workbench with MATERIAL color mode
- Principled BSDF `Base Color` set to that exact RGBA value.

The 5 models are generated by agy, smoke-tested on Yamada's pinned Blender 5.2.2
in a restricted mount and network namespace and validated before being committed.
The full rendering workflow emits 144-frame turntables, GLBs, .blend, and previews.
Outputs are stored separately from the original five-model dataset.
