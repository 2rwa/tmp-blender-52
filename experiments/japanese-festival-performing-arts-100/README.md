# Japanese festival and performing arts: 100 precise low-poly test assets

This is a separate dataset from crafts and crafts-rebuilt.

- 100 individually named festival, shrine, theatre, folk dance, instrument and costume items.
- 10 categories of 10, each exported independently.
- Large floats, hoko and yagura retain individual joinery, rooftop details, wheels, railings, banners and carvings.
- Blender 5.2 Workbench, material colors, 500 x 400, 144 frames at 24fps, 6 s.
- Outputs: .blend, .glb, preview.png, turntable.mp4, metadata.json.
- Auto-check: catalog count, source compile, frame count, GLB header, mesh/face counts and visible preview area.
- Source code is deterministic; no external models or copyrighted textures.

The project is experimental. Automated validations ensure that files are usable and visible, but do not constitute historical or artistic authenticity verification. Particularly complex stage masks and costumes use stylized geometry.
