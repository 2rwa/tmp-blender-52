# Chesterfield wingback armchair — Workbench HD

Editable procedural oxblood-leather armchair for Blender 5.2.2.

- 4 individually generated high-resolution diamond-tufted surfaces: seat, back, left/right arm inserts
- Recessed upholstery buttons, sewn diagonal welt/seam curves
- Thick rolled arms and scroll ends, sculpted curved wingback ears
- Antiqued brass nailheads, individual turned walnut bun feet
- Blender Workbench, 1280 × 720, 96 frames at 24 fps, 360° animated orbit camera
- Existing Actions pipeline renders, validates, commits .blend/MP4/PNG results, builds Pages and exposes the .blend link

Model includes sculpted rather than physically simulated leather; all parts remain editable.
