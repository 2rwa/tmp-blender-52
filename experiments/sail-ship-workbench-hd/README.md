# Three-masted sail ship — Workbench HD

Procedural Blender 5.2.2 model, **1280 × 720**, 120 frames at 24fps.

- Separate, editable wooden hull / deck / three masts / five yards / six curved canvas sails / rigging / rail posts / portholes.
- Animated camera completes one 360-degree orbit; ship subtly pitches, rolls and bobs.
- Styled ocean is an illustrative mesh, not simulated fluid.
- Uses **BLENDER_WORKBENCH**, not Cycles or EEVEE.
- Actions validates Workbench, 720p, Blender 5.2.2, parts census, visual contrast and visible motion.
- Existing reusable render job persists the .blend and MP4 to results; Pages gallery provides a .blend download.

Workflow: Sail ship workbench HD. Sources: scene.py, geometry.py, ship.py, validate.py.
