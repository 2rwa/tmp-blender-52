# Sail Ship — Workbench Wireframe HD Turntable

Actual 1280×720 Blender 5.2 Workbench wireframe render from the bridged `Sail ship.blend`.
The camera makes one full orbit over 10 seconds at 24 fps (240 actual rendered frames).

Validation uses `ffprobe` for the MP4 stream/container metadata and `ffmpeg -xerror` for a full decode check.
